Selection Launcher

Turn selected text into an action.

Search or copy without reaching for a context menu.

Behavior

Open the bubble from the keyboard, or search immediately with the first enabled engine.

Defaults: Ctrl + Shift + . opens the bubble; Alt + 1 searches immediately. Chrome manages changes at chrome://extensions/shortcuts.

Search engines

Each enabled engine becomes a button in the selection bubble.
